# Security policy

## Supported versions

Shoostr is experimental. Security fixes target the current `main` branch.
There are no published releases or separately maintained older release branches.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/SuppieRK/Shoostr/security/advisories/new).
If you cannot use GitHub, email [suppie.rk@gmail.com](mailto:suppie.rk@gmail.com).
Do not publish exploit details or sensitive information in a public issue or pull request.

Include the affected commit or version, configuration, impact, reproduction steps,
and a minimal example when possible. Remove credentials and personal data from evidence.
The maintainer will assess the report and coordinate any fix and disclosure privately.
No response-time or remediation-time guarantee is offered.
