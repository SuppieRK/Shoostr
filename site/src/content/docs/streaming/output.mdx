## Description

Use `startStream(...)` to write a response incrementally, or `response.input(...)` to transfer an input source through the same bounded output buffer.
Streaming bypasses the finite-body limit; `Options.streamBufferBytes()` bounds the application buffer, not the total transfer or its duration.
Writes flush when the buffer fills, and `flush()` sends pending bytes explicitly; both wait for the transport before the buffer is reused, providing backpressure to the handler.

Starting the stream commits the response, so select its status and headers first and do not mix streaming with a staged body or file transfer.
Text writes use UTF-8 even if different charset metadata was supplied; encode other charsets yourself and write matching bytes instead.
For replaceable, buffered output, use [finite response bodies](../../responses/bodies/), or use [file downloads](../../resources/downloads/) for a transfer staged from a path.

## Example

The `/chunks` handler flushes the CSV header before writing two records; returning from the handler finishes the stream and sends any remaining bytes.
The `/input` handler opens a report and passes it to `response.input(...)`, which closes that source before returning, including when reading or output fails.

Keep the response and stream on the handler thread and within its lifetime; retaining either for background work does not keep the HTTP response open.
Do not close `Response` yourself. Release handler-owned input resources when their use ends.
After the handler returns, the framework still completes pending output and the final transport write.
An admission permit protecting the HTTP exchange must remain held through terminal request completion;
see [stream admission](../../lifecycle/executors/#compose-stream-admission).
A disconnected client or a failure after commitment aborts output rather than producing a replacement error body; see [exception recovery](../../errors/exceptions/) for that boundary.
For event framing and client replay, use [server-sent events](../sse/).
