## Description

Register a GET endpoint at `/hello` that returns `Hello, Shoostr!` as plain text.

With Shoostr core available in your Java 21 project, this example uses your existing SLF4J logging configuration.
The [library reference](../libraries/) covers the core, test, and optional libraries.

Shoostr's public interfaces can change.

The default listener binds to all IPv4 interfaces on port `8080`, not only to localhost.

## Example

`application()` builds an unstarted `Shoostr` application and leaves its lifetime with the caller.
Construction registers Shoostr's JVM shutdown hook without starting the listener.

Launching `HelloExample` invokes `main`, which starts the listener; normal JVM shutdown closes the application through its hook.
Callers that manage the application directly must close it even if it never starts.

The `TestServer` fixture runs the application on an available loopback port and owns its shutdown, keeping the test independent of the application's default binding.
