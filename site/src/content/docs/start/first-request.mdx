## Description

This first application answers `GET /hello` with `Hello, Shoostr!` as plain text. Follow one request from registration to its handler, then verify the response over HTTP.

A `Shoostr` instance is the application: it holds the serving configuration and the routes registered before startup. A **route** associates an HTTP method and path with a **handler**, the Java callback that performs the work. Shoostr passes that callback a `Request` for incoming data and a `Response` for the outgoing status, headers and body. This endpoint runs on Shoostr core alone, with no additional integration.

Here, `routes(...)` supplies the registration view, `get(...)` binds the `HTTP GET` path, and `response.text(...)` prepares the text response.

Use Shoostr core in a Java 21 project with your existing SLF4J logging configuration. See
[install Shoostr with Maven or Gradle](../libraries/) for both application and test dependencies.
Public interfaces can change.

The complete class below separates configuration from startup. `application()` returns an unstarted application; `main(...)` starts its listener.

The default listener accepts traffic on all IPv4 interfaces at port `8080`, not only loopback. Constructing the application also registers a JVM shutdown hook, so normal JVM shutdown closes a launched application.
