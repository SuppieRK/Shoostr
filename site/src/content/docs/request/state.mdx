## Description

Pass values from a hook to the endpoint handler without putting them in global or session state. A
[request hook](../../lifecycle/hooks/) runs at a named phase of request handling. The attributes it sets belong to
that exchange.

Set an attribute with `attribute(name, value)` and read it with `attribute(name)`. Keys are case-sensitive. Setting
the same key again replaces its value. Assigning `null` removes the key.

Keep the live `Request` on its owning thread and within the request-handling lifetime. Shoostr throws
`IllegalStateException` if you access it from another thread or after that lifetime ends. Capture the values or
snapshots you need while handling the request so you can use them later.

Parameter, header, and cookie collections are deeply immutable snapshots you can keep after the exchange.
`attributeMap()` returns an immutable copy of the bindings. The values are the original application objects,
so changes to a mutable value are visible through the snapshot. If you share a mutable value across threads,
coordinate access yourself.

After a WebSocket upgrade, read detached values from [`WebSocketConnection`](../../websockets/managed/).

## Test

The HTTP tests create the app with `RequestStateExample.application()`. `TestServer` starts it on an available
loopback port and shuts it down when the fixture closes.

Two requests to `/greeting` get different request IDs. The first selects French and the second gets the default
English greeting. The attribute test replaces one binding and removes another. The snapshot keeps both original
bindings, and a change to the original list is visible through it. Attempts to modify the snapshot map itself fail.

A worker thread gets `IllegalStateException` when it tries to read the request's attributes or headers as maps
or set an attribute. The header snapshot captured on the owning thread still has its original value after the
response and a later request.
